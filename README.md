# CPM Plugin+

Plugin de Blockbench do **[Customizable Player Models](https://github.com/tom5454/CustomPlayerModels)** (CPM), de tom5454, com correções e ferramentas novas pra quem modela e anima pro CPM.

**Instalar:** Blockbench > Arquivo > Plugins > Carregar plugin por URL e cole:

`https://raw.githubusercontent.com/solismissus-bot/CPM-Plugin-Plus/main/plugin/cpm_plugin_plus.js`

Desinstale o plugin oficial do CPM antes. Esse link sempre traz a versão mais nova. Quem instalou pelo link do gist não precisa fazer nada.

Guia de uso e novidades: [gist do CPM Plugin+](https://gist.github.com/solismissus-bot/26923a343013328804c2bc12f7c9de6c).
